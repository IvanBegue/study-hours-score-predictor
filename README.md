# study-hours-score-predictor
Supervised ML project using Linear Regression to predict student performance from study hours data.
# Study Hours Score Predictor

A Machine Learning mini-project developed as part of my MSc in Artificial Intelligence With Machine Learning.  
This project analyzes the relationship between students' study hours and their exam scores using Supervised Machine Learning techniques.

---

## Project Overview

The objective of this project is to predict student marks based on the number of hours studied.

The project includes:

- Data visualization
- Model training
- Prediction and evaluation

This project demonstrates the practical implementation of Regression algorithms in Machine Learning.

---

## Dataset

The dataset contains:

| Feature | Description |
|---------|-------------|
| Hours Studied | Number of hours a student studied |
| Marks | Student exam score |
